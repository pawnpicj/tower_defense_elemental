Elemental Frontier.

ข้อมูลโปรเจกต์และแนวทางภาพสำหรับเกม Tower Defense

ต้นแบบ Three.js ที่มีป้อมธาตุดิน น้ำ ลม ไฟ และสายฟ้า สนามรบแบบไอโซเมตริก ศัตรูเดินตามเส้นทาง และระบบทดสอบสกิลพร้อมเสียง

สถานะปัจจุบัน: ตัวเกมยังเป็น 3D Pixel Art ส่วนภาพ 3 สไตล์ด้านล่างเป็นคอนเซปต์ที่สร้างด้วย ImageGen เพื่อใช้เลือกทิศทางภาพ ยังไม่มีการเลือกหรือนำสไตล์ใหม่ไปใช้ในตัวเกม

ค่าทั้งหมดเป็นค่าทดลองจากโปรเจกต์นี้ ไม่ใช่ข้อมูลสมดุลจาก King of Defense 2

ป้อมDMGระยะช่วงยิงความสามารถ
ดินSTONE GUARDIAN564.7 m1.8 sระเบิดหิน · สตันเป็นวง
น้ำTIDAL SANCTUM264.8 m1.05 sคลื่นน้ำ · ลดความเร็ว 50%
ลมZEPHYR SPIRE185.1 m0.48 sคมลม · ยิงเร็วและผลักกลับ
ไฟEMBER CITADEL344.5 m1.25 sลูกไฟ · เผาและระเบิดหมู่
สายฟ้าSTORM OBELISK385 m1.15 sสายฟ้าชิ่ง · สูงสุด 3 เป้าหมาย

รายละเอียดสกิล

  • ดิน: ระเบิดรัศมี 1.55 m และสตัน 0.55 วินาที
  • น้ำ: ลดความเร็ว 50% นาน 2.2 วินาที
  • ลม: ผลักศัตรูย้อนเส้นทาง 0.38 m
  • ไฟ: โจมตีหมู่และเผา 3 วินาที ครั้งละ 8 DMG ทุก 0.5 วินาที
  • สายฟ้า: ชิ่งสูงสุด 3 เป้าหมาย ดาเมจลดลง 22% ต่อการชิ่ง

สนามทดสอบ

8แท่นป้อม
5ป้อมเริ่มต้น
20พลังฐาน
12ศัตรูเวฟแรก

เวฟถัดไปเพิ่มศัตรูครั้งละ 3 ตัวและเพิ่ม HP 20% ต่อเวฟ ศัตรูทั่วไป 600 HP / แทงก์ 1,000 HP ป้อมเลือกโจมตีศัตรูที่เดินไกลที่สุดในระยะ

วาง เปลี่ยน หรือนำป้อมออกได้ พร้อมหยุดเกม เร่งเวลา 1x / 2x / 3x และรายงานดาเมจแยกธาตุ

ตัวเกมปัจจุบัน / การรันโปรเจกต์

ภาพจากตัวเกมจริง: Orthographic isometric, pixel render 2x / 3x / 4x ผู้ใช้รายงานว่ารายละเอียดไม่ชัด จึงมีภาพคอนเซปต์ทางเลือกในหน้า 3-5

รันในเครื่อง

npm install
npm run dev

เปิด http://127.0.0.1:5173/ หรือใช้ start-preview.cmd

สร้าง production build

npm run build
npm run preview

เปิด http://127.0.0.1:4173/

ผลตรวจสอบ

Build ผ่าน การทดสอบเบราว์เซอร์ตรวจกล้องไอโซเมตริก ซูม วางป้อม สกิลและเสียงทั้ง 5 ธาตุ รวมถึงหน้าจอมือถือผ่าน ไม่พบข้อผิดพลาด JavaScript ในรอบตรวจ

ขั้นถัดไป: เลือก Toon / Cel-shaded, Stylized Low-poly หรือ Voxel ก่อนเริ่มเปลี่ยนงานภาพจริง ข้อมูลเครื่องอ่านได้อยู่ใน docs/project-data.json และภาพคอนเซปต์เต็มอยู่ใน docs/concepts/
